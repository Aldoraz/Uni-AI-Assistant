# GenAI Learning Assistant

## Idea
As part of a GenAI module in my Masters program, I'll create an agent that supports me in my work.
Specifically an learning assistant that can

- Retrieve context from documents via RAG
- Store relevant information long term (memories, history...)
- Use multiple relevant tools via MCP (File System, Web Search, Image Generation...)+
- Support Voice in-/output
- run local and cloud models
